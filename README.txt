マレットゴルフスコア表（アプリ用ファイル一式）

ファイル
  index.html            アプリ本体
  manifest.webmanifest  アプリ名・アイコンの設定
  sw.js                 オフラインで動かすための設定
  icon-192.png / icon-512.png / apple-touch-icon.png  アイコン

【すでにGitHubに前の版を置いている場合（上書き）】
  1. GitHubで自分のリポジトリを開く
  2. 「Add file」→「Upload files」で、このフォルダの6ファイルをすべてアップロード
     （index.html と sw.js と manifest.webmanifest は同じ名前なので上書きされます）
  3. 「Commit changes」をタップ
  4. 1〜2分待ってから、アプリを開いて、いったん閉じてもう一度開く
     （古い画面が出るときは、もう一度開き直してください）
  ※ 以前のスコアは、新しい版でも日付つきでアーカイブに残ります。

【はじめて置く場合】
  GitHubでリポジトリ（Public）を作り、6ファイルをアップロードして、
  Settings → Pages → Branch を main にして Save。
  数分後に https://ユーザー名.github.io/リポジトリ名/ で開けます。

【ルーム機能について】
  ・ルームは公開の中継サーバー（HiveMQ / EMQX / Mosquitto）を使います。アカウントは不要です。
  ・ルーム番号が合言葉の代わりです。番号を知っている人は誰でも参加できます。
  ・共有されるのはスコア表（名前とスコア）だけです。マップなどは共有されません。
  ・端末の通信が切れても、つながり直すと自動で復帰します。
